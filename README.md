# 測量案件排程

苑裡・通霄地籍測量案件的排程管理工具，從原本的 Excel 排程表（常用ID／母表／各月份工作表）改成網頁介面。

- **線上版**：發佈在 claude.ai，資料存在雲端資料庫，可分享給同事共用。
- **離線版**：單一 HTML 檔，按兩下就能用，不需安裝或網路；資料存在該電腦的瀏覽器中。

## 功能

- 總覽：本月進度、補正中、逾期未結、通知未寄出、接下來的案件、補正中案件（剩餘天數與到期警示）
- 排程表：以今天為中心前後 15 天，往上下捲動載入更早／更後；回到今天、跳到任一日期；工作日空檔、搜尋與篩選
- 行事曆：月曆檢視，每筆顯示種類、時間、案件編號、地段、地號、申請人；點日期直接排入案件
- 案件：排定日期＋時間、案件編號、通知狀態、儀器（可複選）、辦理情形（完成／補正／駁回／撤回自動記錄日期時間到備註）
- 現場抓點：辦理情形選「現場抓點」並填日期時間，那天的行事曆與排程表會顯示一筆，點了跳到原案件
- 擴大檢測：和延期一樣，原案件留作紀錄（不算逾期），複製一筆到新日期時間
- 延期：辦理情形選「延期」，填延期理由，可先不排日期；可產生 A4 延期便簽（一般／法院兩種範本）
- 連件：一個案件帶多件（各自的案件編號、種類、段代碼、地號），其餘欄位共用；子件可拆件成獨立案件
- 休假／出差／上課：三種顏色、斜線標示
- 段代碼對照表、代理人通訊錄、測量種類皆可編輯
- 匯入原本的 Excel 或備份檔；匯出 Excel（沿用原格式，每月一張工作表）
- 自動備份（離線版）：選一個資料夾（建議雲端硬碟同步資料夾），修改後自動存備份檔
- Map-Scheduler 案件同步（離線版）：選測量員自動抓案件，匯入前確認、不重複，日期時間有變動會提示
- 版本更新紀錄：點左下角版本號查看本版新功能與歷次更新

## 手機查閱版

`docs/` 是手機專用的唯讀頁面，以 GitHub Pages 發布於 https://gn01918004-hub.github.io/work-paper/ 。
在手機選擇電腦版的備份檔（`survey-backup-latest.json`，建議放在雲端硬碟同步資料夾）後，就能查看接下來的案件與未結案件。
頁面本身不含任何案件資料，資料只存在該手機的瀏覽器中；可加到主畫面，離線也能開。
也可設定「開啟時自動讀雲端硬碟」：使用者在自己的 Google 帳號部署一支 Apps Script 網頁應用程式（程式碼由頁面產生，含隨機密鑰，只讀取 `survey-backup-latest.json`），手機每次開啟時自動抓最新的備份。

## 專案結構

```
src/survey-cases.html   原始頁面（線上版直接發佈這個檔）
data/seed.json          內建常用資料：代理人通訊錄、測量種類、9～11 月工作日（不含案件）
vendor/                 SheetJS 0.18.5（Apache-2.0），離線版內嵌用
tools/build.py          打包離線版
dist/使用說明.txt       隨離線版附上的使用說明
release/                最新離線版（survey-schedule.zip）與版本檔（version.json），供離線版檢查更新
```

## 打包離線版

```bash
python3 tools/build.py            # 內建 data/seed.json 的常用資料（散佈與發佈用）
python3 tools/build.py --no-seed  # 連常用資料都不內建，完全空白（只產生 dist/，不更新 release/）
python3 tools/build.py --test     # 測試版：資料與正式版分開，輸出到 dist/測量案件排程-測試版，不更新 release/
```

產出 `dist/測量案件排程/測量案件排程.html` 與 `dist/測量案件排程.zip`，並更新 `release/`。

## 發佈新版本

1. 修改 `src/survey-cases.html`，把 `VERSION` 改成新版本號，並在 `CHANGELOG` 陣列最前面加上這一版的說明（`CHANGELOG.md` 同步更新）
2. 執行 `python3 tools/build.py`
3. 提交並推送（包含 `release/`）。已安裝的離線版下次開啟時就會跳出新版通知

## 注意

自 v3.3.2 起，`data/seed.json` 與發佈的離線版不再含案件資料，只保留代理人通訊錄（含電話）。本倉庫為公開，任何人都能看到這些內容；v3.3.1 以前的 Git 歷史仍保有原本 9～11 月的案件資料。
